# ⚡ 电缆载流量计算器

三线铜/铝电缆载流量计算工具，基于国标 GB/T 16895.15 (IEC 60364-5-52)。

## 功能

- 🔍 根据截面积/材质/敷设方式/温度计算载流量
- 📊 温度修正、并列回路修正、敷设方式修正
- ⚡ 电压降计算（三相/单相）
- 📖 常用电缆载流量速查表
- 📱 PWA 支持，可安装到手机桌面
- 📴 离线可用

## 数据来源

- GB/T 16895.15-2002 建筑物电气装置
- IEC 60364-5-52 低压电气装置
- 基准条件：PVC/XLPE 绝缘, 30°C 环境温度, 空气中敷设
